Tablet and phone

  • Desktop compact (≤ 1100 px): the tray overlays the calendar instead of docking, and closes after a confirm.
  • Tablet rail: one tray toggle with the Inbox count at the top of the rail.
  • Phone: the tray's tabs become bottom-bar tabs (Inbox, Items). Review is a full-height sheet with the confirm button pinned at the bottom. In a narrow desktop window, confirming works as usual. In the browser build there is no Inbox, because actions are desktop only.
  • Browser build: no tray (actions are desktop only). The time lanes still render if worklogs are collected.

States

  • Agent off or not set up: the Inbox holds only your own saved drafts. The status line reads “No agent connected · Set up”.
  • Draft no longer valid (item closed, setting turned off, token lacks the permission): re-checking fails. The card turns grey with the reason and offers only Discard.
  • Outcome unknown after confirm: the card stays in the Inbox as a sticky warning (“Check ACME-163's worklogs before trying again”) rather than disappearing.
