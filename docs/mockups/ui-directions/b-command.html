The four views stay as they are. One command bar (⌘ K, or the field in the header) becomes the way into everything new. It searches work items and your own activity side by side, runs verbs (log time, new ticket, move, assign, check in) and hands requests to the agent. Its forms are small. The confirm step is the same preview the other directions use, shown inside the bar.

Tablet and phone

  • Tablet rail: unchanged, plus a search icon at the top of the rail that opens the bar.
  • Phone: the bar is a full-screen sheet with the same groups. A Search tab joins the bottom bar (or the header gets a search button). Verb mode turns into a stacked form, so the token idea is lost on phones.
  • Browser build: the bar still searches your activity. Actions and items are hidden (desktop only).

States

  • Loading: local groups (verbs, activity) appear at once. The remote group shows a single row with a spinner, so the list doesn't jump.
  • Errors: a failed remote group collapses to one row (“Work Jira didn't answer · Retry”). The rest of the bar works.
  • Not allowed: a verb the user turned off isn't listed. Typing it (“comment”) shows one muted row: “Commenting is off for Work Jira · Open Access settings”.
  • Discoverability: needs a first-run hint and visible buttons elsewhere (detail action bar, selection bar). Otherwise people never find the bar.
